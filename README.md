# 🤖 AI Resume Analyzer

An AI-powered Resume Analyzer built with **Python and Streamlit** that helps users analyze their resume against a target job description.

The application evaluates the resume, calculates an ATS score, identifies skill gaps, provides resume improvement suggestions, recommends suitable job roles, and generates a downloadable PDF report.

## 🧠 Resume Analysis

The application analyzes the uploaded resume and provides:

- 📊 ATS compatibility score
- 📝 Resume section analysis
- 🎯 Matched skills
- ❌ Missing skills
- 🔍 Skill gap analysis
- 💡 Resume improvement suggestions
- 💼 Suitable job recommendations

---

## 📊 ATS Score Analysis

The application compares the candidate's resume with the target job description and calculates an ATS compatibility score.

The dashboard displays:

- Overall ATS Score
- Matched Skills
- Missing Skills
- Resume Skills
- Target Job Skills
- ATS Alignment Status

This helps users understand how well their resume matches the requirements of a particular job.

---

## 🔍 Skill Gap Analysis

The Skill Gap Analysis identifies important skills required by the target job description that are missing from the uploaded resume.

### It shows:

🟢 **Matched Skills**

Skills that are present in both the resume and job description.

🔴 **Missing Skills**

Skills required by the job description but not sufficiently represented in the resume.

This helps candidates understand which skills they should improve or add to their resume.

---

## 💡 Smart Resume Suggestions

The application provides actionable suggestions to improve the resume.

Suggestions may include:

- Improving the professional summary
- Adding missing technical skills
- Improving project descriptions
- Adding measurable achievements
- Improving keyword usage
- Strengthening resume sections
- Better matching the target job description

---

## 💼 Job Recommendations

Based on the resume profile and analyzed skills, the application recommends suitable job roles.

Example roles may include:

- 💻 Python Developer
- 🤖 Machine Learning Engineer
- 📊 Data Analyst
- 🧠 AI Engineer
- 🌐 Software Developer
- 📈 Data Scientist

The recommendations are based on the skills detected from the resume.

---

## 📄 PDF Report

The application generates a downloadable PDF report containing the resume analysis results.

The report can include:

- ATS Score
- Matched Skills
- Missing Skills
- Skill Gap Analysis
- Resume Suggestions
- Job Recommendations

Users can download the report and use it for further resume improvement.
